# Design System

## Visual Direction

DriverOps should feel like an operations console, not a casual consumer app.

Reference qualities:
- dark background
- high contrast
- restrained accent color
- dashboard density
- clear status language

## Status Colors

GO: emerald
PREPARE: blue
WAIT: yellow
STAND_DOWN: red

## Component Rules

Cards should answer one question.
Metrics should include context.
Alerts should explain why they matter.
Recommendations should include reasoning.
