# DriverOps Alpha 0.1 Plan

Status: ready to begin alpha operations  
Architecture: frozen  
Goal: prove whether DriverOps improves real operating decisions.

## Alpha 0.1 operating loop

1. Open Prelaunch Mode.
2. Confirm vehicle cost assumptions.
3. Open Operator Briefing.
4. Create a Mission Mode execution plan.
5. Run one real test shift.
6. Complete closeout.
7. Compare forecast vs actual.
8. Generate or record mission review.
9. Export snapshot.
10. Review whether recommendations improved.

## Success criteria

Alpha 0.1 is successful when DriverOps has:

- 5 completed missions
- 5 closeouts
- 5 forecast-vs-actual comparisons
- 1 imported real rideshare data file
- 1 exported snapshot
- 1 weekly operating review
- 0 failing quality gates
- 0 npm audit vulnerabilities

## Development rule

During Alpha 0.1, do not add new engines.

Allowed work:

- bug fixes
- onboarding
- UX polish
- import improvements
- persistence hardening
- validation reporting
- documentation
- tests
