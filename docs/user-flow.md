# User Flow

## First Use

1. Open DriverOps.
2. Configure vehicle profile.
3. Review cost-per-mile baseline.
4. Set driving target.
5. Plan first shift.

## Daily Use

1. Check dashboard recommendation.
2. Complete readiness checklist.
3. Start shift.
4. End shift.
5. Review net profit.
6. Save closeout.
7. Receive next recommendation.

## Weekly Use

1. Review profit against target.
2. Review best and worst windows.
3. Check vehicle costs.
4. Confirm tax reserve.
5. Adjust operating rules.
